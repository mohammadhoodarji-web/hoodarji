# قالب وردپرس همراه‌یار

## نصب
1. پوشه‌ی `hamrahyar` را (یا همین فایل زیپ را) از مسیر «نمایش ← پوسته‌ها ← افزودن» بارگذاری و فعال کنید.
2. با فعال‌سازی، یک بار محتوای نمونه ساخته می‌شود: ۶ پرستار، ۸ کالا و دو صفحه («پنل همراه بیمار» و «ورود / ثبت‌نام»).
3. «تنظیمات ← پیوندهای یکتا» را یک بار ذخیره کنید تا نشانی‌های `/nurses/` و `/shop/` کار کند.

## ساختار
- صفحه‌ی اصلی (`front-page.php`): معرفی همراه‌یار، همه‌ی بخش‌ها با متن اصلی.
- فهرست پرستاران `/nurses/` با فیلتر نوع مراقبت، شهر و مرتب‌سازی؛ پروفایل هر پرستار.
- فروشگاه تجهیزات `/shop/` با دسته‌بندی و جستجو.
- قالب‌های صفحه: «پنل همراه بیمار» و «ورود / ثبت‌نام».

## امکانات نسخه‌ی ۱.۱
- برای هر یک از ۸ کالای نمونه تصویر اختصاصی در خود قالب قرار گرفته است؛ تصویر شاخصی که مدیر سایت بارگذاری کند همیشه اولویت دارد.
- در «نمایش ← سفارشی‌سازی» تنظیم رنگ اصلی و تیره، عرض محتوا، گردی گوشه‌ها و متن‌های بخش اصلی قابل تغییر است.
- از «نمایش ← فهرست‌ها» منوی پاورقی را مدیریت کنید و از «نمایش ← ابزارک‌ها» سه ستون پاورقی را بسازید.
- قالب با ویرایشگر بلوکی وردپرس، Elementor و WooCommerce سازگارتر شده است.
- راهنمای افزونه‌ها از مسیر «نمایش ← افزونه‌های پیشنهادی» در دسترس است.

## ویرایش
- پرستاران و کالاها از منوهای «پرستاران» و «فروشگاه تجهیزات» در پیشخوان.
- متن صفحه‌ی اصلی و صفحه‌ها در `inc/content.php`.
- متن پاورقی از «شخصی‌سازی ← پاورقی».
- منو: یک منو بسازید و به «منوی اصلی» اختصاص دهید؛ تا آن زمان منوی پیش‌فرض نمایش داده می‌شود.

## افزونه‌های پیشنهادی
- Elementor: طراحی بصری صفحات و لندینگ‌پیج.
- WooCommerce: فروشگاه، سبد خرید، سفارش و پرداخت.
- Advanced Custom Fields: فیلدهای پیشرفته برای کالاها و پرستاران.
- WPForms Lite: فرم‌های تماس و درخواست خدمات.
- Rank Math SEO: ابزارهای سئو.
- LiteSpeed Cache: کش و بهینه‌سازی، در صورت استفاده از سرور سازگار.

این افزونه‌ها به‌صورت اجباری داخل ZIP قرار نگرفته‌اند؛ از مخزن رسمی وردپرس نصب می‌شوند تا نسخه و به‌روزرسانی امن داشته باشند.

## نکته‌ها
- فونت وزیرمتن از jsDelivr بارگذاری می‌شود.
- چت، سبد خرید و پرداخت امانی کارکرد هستند و در قالب نیامده‌اند؛ برای آن‌ها افزونه (مثل ووکامرس) لازم است.

## سازگاری ویرایش کامل با Elementor

این نسخه برای کار با Elementor آماده شده است:

- پشتیبانی قالب از Elementor فعال است و جایگاه‌های استاندارد هدر، فوتر، محتوای تکی و آرشیو برای Theme Builder ثبت می‌شوند.
- نوع محتوای «صفحه»، «نوشته»، «پرستار» و «محصول همراه‌یار» برای استفاده از Elementor پشتیبانی می‌شود.
- اگر صفحه‌ی اصلی یا محتوای تکی پرستار/محصول با Elementor ساخته شده باشد، محتوای پیش‌فرض قالب جای آن را نمی‌گیرد.
- استایل‌های پایه برای راست‌چین، فونت فارسی، تصاویر و نمایش واکنش‌گرا در Elementor اضافه شده‌اند.

### شروع کار

1. افزونه Elementor را از بخش افزونه‌های وردپرس نصب و فعال کنید.
2. از مسیر تنظیمات ← عمومی، عنوان و معرفی سایت را بررسی کنید.
3. از بخش برگه‌ها، صفحه‌ی موردنظر را با «ویرایش با Elementor» باز کنید.
4. برای طراحی هدر و فوتر یا قالب‌های سراسری آرشیو/پرستار/محصول، از Theme Builder استفاده کنید (امکانات Theme Builder برای برخی قالب‌ها به Elementor Pro نیاز دارد).
5. برای ویرایش محتوای پرستارها و محصولات اختصاصی، هر مورد را از منوی مربوطه باز کنید و با Elementor ویرایش کنید. داده‌های اختصاصی مانند قیمت، شهر و امتیاز همچنان در فیلدهای قالب نگهداری می‌شوند.
6. برای فعال‌کردن نوع محتوا در تنظیمات افزونه، به Elementor ← تنظیمات ← عمومی ← انواع نوشته بروید و گزینه‌های موردنیاز را فعال کنید.

**توجه:** نصب افزونه Elementor داخل فایل قالب انجام نشده است. قالب بدون افزونه نیز مانند قبل کار می‌کند. برای طراحی قالب‌های سراسری هدر/فوتر و آرشیوها ممکن است Elementor Pro لازم باشد؛ این ZIP افزونه‌ی پولی یا لایسنس آن را شامل نمی‌شود.
